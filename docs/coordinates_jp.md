# 点群を座標系に乗せる

GNSS（RTK か PPK）を使った結果は、現場付近を原点にしたローカル座標です。X＝東、Y＝北、Z＝上（単位 m）で、原点の緯度・経度・楕円体高（WGS84）は出力フォルダーの `coordinate_frame.json` にあります。Z は原点の接平面からの高さで、標高ではありません。

UTM や各国の平面直角座標系などに乗せたいときは、[PDAL](https://pdal.org/) で変換します。そのためのパイプラインを、出力フォルダーに `pdal_to_crs.json` として書き出しています（GNSS を使ったときだけ。「軌跡・画像姿勢の出力」で書きます）。原点は書き込み済みです。

## 変換

PDAL のインストールは [PDAL のページ](https://pdal.org/) を見てください。出力フォルダーで実行します（ファイル名は今いるフォルダーから探します）。

```
cd <作業フォルダー>/output
pdal pipeline pdal_to_crs.json
```

たとえば `pointcloud_colorized.laz` を変換して、`pointcloud_colorized_crs.laz` に書きます。変換先の座標系は LAS に書き込まれます。

- **変換先**：既定は原点の UTM の帯（WGS84、EPSG:326xx／327xx。極地方では UPS）です。ほかの座標系にするときは、EPSG コードを指定します。JSON の `filters.reprojection` の `out_srs` を書き換えるか、コマンドで指定します。日本の平面直角座標系は EPSG:6669（第 I 系）〜6687（第 XIX 系）です。

  ```
  pdal pipeline pdal_to_crs.json --filters.reprojection.out_srs=EPSG:6678
  ```

  JSON で書き換えた変換先は、アプリが JSON を書き直すとき（「軌跡・画像姿勢の出力」「点群生成」「着色」のやり直し）も引き継ぎます。座標は 0.1 mm 刻みで書くので、変換先は m 単位の投影座標系にしてください。緯度経度（EPSG:4326 など）にするときは、`--writers.las.scale_x=1e-9 --writers.las.scale_y=1e-9` のように刻みも指定します（そのままだと 0.0001 度、約 10 m 刻みになります）。

- **ほかのファイル**：入力と出力のファイル名を指定します。

  ```
  pdal pipeline pdal_to_crs.json --readers.las.filename=trajectory.las --writers.las.filename=trajectory_crs.las
  ```

入力には、出力フォルダーの点群のうち、今の座標系で作られたいちばん新しいものを書きます（なければ軌跡 `trajectory.las`）。「点群生成」や「着色」をやり直したときも、それに合わせて書き直します。

法線（と軌跡の向き）などの追加の属性は、既定では書きません。座標系に乗せた点群は GIS で使うことが多いのに、QGIS 3.44 では追加の属性（LAS 1.4 の Extra Bytes）を持つ LAS 1.4 のファイルが開けないためです（[QGIS の Issue #63906](https://github.com/qgis/QGIS/issues/63906)）。残すときは `--writers.las.extra_dims=all` を付けます。

## 注意

- **格子データが要る変換**：標高を含む座標系や、国によっては水平の変換にも、PROJ の格子データ（ジオイドのモデルなど）が要ります。格子データがないと、PROJ は**エラーを出さずに精度の低い変換に切り替えます**（標高なら、楕円体高のまま「標高」と書かれます）。環境変数 `PROJ_ONLY_BEST_DEFAULT=YES` を設定すると、その場合にエラーで止まります（PROJ 9.2 以降）。止まったときにできた出力のファイルは使わないでください。格子データは `projsync --file <名前> --system-directory` で、PROJ のデータのフォルダーに入れます（`--system-directory` を付けないとユーザーのフォルダーに入り、PDAL からは見つからないことがあります）。

  ```
  $env:PROJ_ONLY_BEST_DEFAULT = "YES"       # PowerShell（bash なら export PROJ_ONLY_BEST_DEFAULT=YES）
  ```

- **高さ**：Z は楕円体高のままです。標高にするには、標高を含む座標系を変換先にします。日本なら、平面直角座標系と JGD2024 の標高の組み合わせ（第 X 系なら EPSG:11328）で、ジオイド 2024 の格子データ `jp_gsi_jpgeo2024.tif` を使います。変換したら、Z がジオイド高の分だけ下がったことを確かめてください。
- **位置の正しさは基準局の座標で決まります**：RTK・PPK の位置は「基準局の座標＋基準局からのベクトル」です。基準局の座標そのものの誤りや、その座標がどの測地系・どの時点（元期）のものかによって、点群全体が m 単位でずれることがあります。地図や既存の測量に合わせたいときは、座標の確かな基準局を使ってください。
- **測地系の変換**：WGS84 から変換先の測地系への変換は PROJ が選びます。地殻変動の大きい地域では、時期を考えた変換が必要なことがあります。
- **向き**：変換するのは位置だけです。法線と軌跡の向き（yaw）を残した場合、それらは回しません。真北と変換先の座標の北（図北）の差の分だけ、向きがずれます（普通は 1° 未満）。
